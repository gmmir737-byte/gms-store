# GMS Store

A modern, full-featured eCommerce website built using React, TypeScript, Vite, Tailwind CSS, and Supabase.

## Features

- User Authentication
- Product Catalog
- Categories
- Search & Filters
- Shopping Cart
- Wishlist
- Checkout
- Order Management
- Admin Dashboard
- Responsive Design
- Dark Mode
- Secure Payments
- Customer Reviews

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase
- React Router
- React Hot Toast
- Lucide React

## Installation

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
